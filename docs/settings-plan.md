# План: понятные настройки и настоящие значки

Решено с владельцем 13 октября 2026 года через `/decide`. Макет: [design/settings-a.html](design/settings-a.html), снимок: [design/settings-a.png](design/settings-a.png).

## Что получаем

- Настройки в духе «Системных настроек» macOS: шесть разделов вместо девяти, простые подписи, у неочевидных пунктов одна серая строка пояснения.
- В разделе «Внешний вид» наверху живой пример чёлки и списка, он меняется вместе с настройками.
- По умолчанию агенты показаны логотипами с цветной точкой состояния.
- Логотипы берутся из установленных приложений. Чужих файлов в репозитории нет.

## Пресеты

В «Внешнем виде» сразу под живым примером переключатель из трёх пресетов: Кратко, Подробно, Всё. Пресет одним кликом выставляет параметры строки, списка, лимитов и карточки. Если человек потом меняет любой из этих параметров руками, переключатель показывает «Своё». Значки и их размер пресет не трогает.

| | Кратко | Подробно (по умолчанию) | Всё |
|---|---|---|---|
| Строка агента | значок и название | плюс модель, действие, время, кольцо контекста | плюс папка и ветка, режим размышлений, стоимость, проект |
| Субагенты | свёрнуты | авто | все развёрнуты |
| Завершённые | 10 мин | 30 мин | 60 мин |
| Остаток лимита | когда мало | всегда | всегда, оба окна |
| Карточка | Сделано, Осталось | все четыре вкладки | все вкладки, все блоки |

Проверка: пресет выставляет ровно эти значения; ручное изменение даёт «Своё»; выбор пресета снова его возвращает.

## Разделы

| Раздел | Что внутри |
|---|---|
| Внешний вид | Живой пример. Пресет: Кратко, Подробно, Всё. Значки картинками: Точки, Логотипы, Логотипы цветом состояния. Размер: Мелкий, Средний, Крупный. «В строке агента»: переключатели модели, действия, ветки, времени, контекста, стоимости; порядок — по кнопке «Порядок…». «Карточка агента»: какие вкладки показывать. |
| Список | Порядок агентов. Группировать по проектам. Субагенты: Авто, Все, Свёрнуты, Не показывать. Показывать завершённых и сколько минут. Что видно в крыле и сколько значков до счётчика. Откуда брать название. |
| Запросы | Отвечать прямо в чёлке. Открывать список, когда агент ждёт. Звук и какой. Горячие клавиши: разрешить, отклонить, открыть список. |
| Лимиты | Показывать остаток: Всегда, Когда мало, Никогда. Предупреждать при N %. Какие окна: 5 часов, неделя. |
| Подключение | Claude Code и Codex: «Подключено» или кнопка «Подключить»; для Codex одна строка про `/hooks`. Доступ к окнам (нужен для «Открыть»). Скрытые проекты. |
| Общие | Запускать при входе. Сбросить всё. О приложении. |

Все нынешние параметры остаются, новых не добавляем.

## Подписи

Без жаргона:

- «хуки» → «подключение»;
- «Accessibility» → «Доступ к окнам»;
- «эффорт» → «Режим размышлений»;
- «Worktree» → «Папка и ветка»;
- «чипы лимитов» → «Остаток лимита»;
- «Метки» → «Значки».

Обращение на «вы» или безлично. Пояснение не длиннее строки.

## Значки из приложений

- **Claude:** иконка приложения с bundle id `com.anthropic.claudefordesktop`.
- **Codex:** приложение `com.openai.codex` (это ChatGPT.app). Иконка не главная, а `Contents/Resources/icon-codex-light.png`; на тёмном фоне — `icon-codex-dark-color.png`.
- Приложение ищется через `NSWorkspace.urlForApplication(withBundleIdentifier:)`. Картинка уменьшается один раз и кэшируется.
- Если приложения нет или файла нет — свои значки (нынешние «Цветные знаки»).
- Точка состояния в правом нижнем углу, с тёмной обводкой, чтобы читалась на иконке.

## Как проверяем

- Проверки:
  - поиск иконки: приложение есть, приложения нет, файла нет;
  - разметка подписей: в `SettingsText` нет слов из списка жаргона.
- Снимки `--snapshot-settings` по каждому разделу и `--snapshot-marks` смотрим глазами и сравниваем с макетом.
- Пересобранное приложение перезапускаем и смотрим живую чёлку.

## Не делаем

- Переключатель языка (английский — отдельной задачей).
- Новые параметры.
- Копии логотипов в репозитории.
