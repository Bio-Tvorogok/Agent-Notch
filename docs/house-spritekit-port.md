# Дом на SpriteKit: полный порт (вариант A)

Решение владельца от 2026-10-22: дом должен вести себя как нынешняя версия на WebKit, а логика целиком переходит на Swift. Фаза 0 (прототип) есть в этой ветке, замеры лежат в `house-spritekit-phase0.md` в заметках сессии.

## Что получим

- Дом из твоих реальных агентов и проектов: острова, мосты, лестницы, лифт, двор, крыша, жители, душ, отдых, чаты, парашюты, погода, сезоны, ночь, пасхалки, клики и зум.
- ≤ 5% CPU с работающими агентами и 0% в покое; 60 fps на питании.
- JS остаётся источником графики. Swift-логика сверяется с JS эталонами, которые снимаются автоматически, поэтому правку в JS видно как упавший тест.

## Как устроено

- **Картинки** снимаются при сборке по частям. Каждая часть привязана к своему началу координат (угол комнаты, начало моста), а не к экрану: оболочка и мебель каждой темы, остров и двор, доски, столбы и верёвки мостов, ступени лестниц, детали лифта под высоту этажа, позы Clawd и жителей. Света несколько корзин по часам, сцена смешивает соседние.
- **Логика** живёт в `NotchCore` (`HouseLayout`, `HouseRoutes`, `HouseSim`): раскладка, маршруты, лифт, лестницы, поведение по состоянию агента, жители, поручения.
- **Эталоны** снимает узловой раннер `Tests/HouseChecks/scene.mjs`, который запускает страницу без экрана. Он выдаёт JSON (раскладку, маршруты, ходы симуляции), Swift-проверки в `scripts/test.sh` сравнивают с ним.
- **Сцена** `HouseScene` собирает узлы из раскладки и частей. Хост: `RoomWallpaper`, SpriteKit единственный рендерер (WebKit убран, см. docs/house-drop-webkit.md).

## Этапы и волны

| # | Что | Проверка |
|---|---|---|
| 1a | `HouseLayout` на Swift: комнаты по проектам, башни и острова, лифт, мосты, лестницы, двор | Совпадение с JS-эталонами для 0–14 проектов и трёх раскладок |
| 1b | Экспорт частей v2: все темы, корзины света, острова, мосты, лестницы, лифт | Сборка по частям даёт тот же кадр, что и страница, отличие > 24 у ≤ 0.1% пикселей |
| 1c | Сцена из раскладки и частей, свет по часам | 5 фикстур: попиксельно против JS |
| 2a | Маршруты и ходьба: `routeTo`, переходы по мостам, лестницам и лифту | Эталонные пути и позиции по времени |
| 2b | Поведение: `placeFor` и `pickSpot` по состоянию, душ, отдых, уход с парашютом, субагенты | Эталонные цели при смене состояний |
| 2c | Жители, кот, пёс, сцены дня | Эталонные расписания |
| 3 | Погода, сезоны, ночь, частицы, пасхалки | Фикстуры дождь, снег, ночь, праздники |
| 4 | Клики, зум, камера, подсказки, другие экраны, скринсейвер | Живой прогон на твоём Mac |
| 5 | SpriteKit по умолчанию | Твоя проверка глазами |

Волна 1: 1a и 1b параллельно, разные файлы и разные worktree. Потом 1c. Каждый кусок делает воркер (Codex или Claude по очереди), проверки я перезапускаю сам, ревью делает Opus.
