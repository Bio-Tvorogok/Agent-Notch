# Самообновление Agent Notch

15 октября 2026. Предложение к реализации; код приложения пока не изменён.

## Результат

Agent Notch проверяет стабильные релизы автоматически раз в сутки и по кнопке «Проверить обновления…» в контекстном меню и в настройках «Общие». Фоновую проверку можно отключить. Найденное обновление показывает версию и описание изменений; загрузка и установка начинаются после нажатия «Обновить». Пользователь выбирает момент перезапуска. Эти два решения подтверждены в decide, раунд `1-0bccb2`.

## Подход

Предлагается Sparkle 2: готовый механизм загрузки, проверки подписи, замены приложения и перезапуска. Свой установщик потребует отдельно поддерживать замену запущенного приложения, восстановление после ошибок и проверку архивов. Открытие GitHub Releases в браузере проще, но оставляет установку пользователю и не даёт самообновления.

Источник — текущий репозиторий GitHub Releases. Лента `appcast.xml` публикуется как вложение стабильного релиза; постоянный адрес — `https://github.com/Forichok/Agent-Notch/releases/latest/download/appcast.xml`. В ленту попадают только выпущенные стабильные версии с подписанным ZIP, без черновиков и предварительных выпусков.

## Изменения

- Добавить один контроллер обновлений в оболочку AppKit. Запускать его при обычном старте приложения, исключив снимки, тестовые сцены и команды установки hooks. Обе кнопки используют этот контроллер; повторная проверка во время текущей недоступна.
- В общих настройках разместить переключатель фоновой проверки и кнопку ручной проверки. Состояние переключателя сохраняется; ручная проверка работает и при выключенной фоновой. Тексты — на русском и английском через существующий механизм локализации. Автоматическую загрузку и установку отключить.
- Подключить одну закреплённую версию Sparkle в `Package.swift` и прямой сборке `scripts/build.sh`. Framework и его помощники включаются в bundle с сохранением символических ссылок и прав. В `Info.plist` добавить адрес ленты и открытый ключ Ed25519. До реализации выбрать конкретную версию и проверить её требования по официальной документации.
- Обновить упаковку и `.github/workflows/release.yml`: после сборки подписывать окончательный ZIP, создавать ленту и включать её в тот же релиз. Закрытый ключ хранить локально в Keychain и в секрете GitHub Actions, открытый — в приложении. Релизная сборка без необходимой конфигурации обновлений должна завершаться ошибкой. `CFBundleVersion` должен возрастать между релизами; сравнение проверяется и для локальных сборок.
- Сохранить пользовательские настройки, видимость вкладок, звуки и hooks. После перезапуска должен использоваться помощник из нового bundle, как предусмотрено текущим запуском приложения.

## Ошибки

Ручная проверка сообщает, что установлена актуальная версия, либо показывает понятную ошибку сети. Фоновая проверка при отсутствии обновлений и временных сетевых ошибках не открывает окна. Неверная подпись, неподходящая версия macOS или ошибка установки не должны заменять рабочую копию. Установка использует штатный механизм Sparkle без собственных команд удаления приложения или снятия quarantine.

## Проверка

1. Проверить настройки обновлений, сохранение старых предпочтений, содержимое ленты и монотонность версий подходящими автоматическими проверками. Выполнить `scripts/test.sh` и `scripts/build.sh`.
2. Открыть свежую сборку: проверить кнопку в меню и настройках, отключение фоновой проверки, сообщения об актуальной версии и ошибке сети. Осмотреть снимок настроек.
3. На двух локальных тестовых версиях с отдельным bundle ID, тестовой лентой и тестовым ключом пройти загрузку, проверку подписи, установку и перезапуск. Повторить с повреждённым архивом: установленная копия должна сохраниться. Проверить сценарий отсутствия прав на запись и поведение установки через Homebrew.
4. Перед заменой `/Applications/Agent Notch.app` получить свежий `origin`, определить default branch через `origin/HEAD`, включить его изменения и повторить проверки. Отрисовать Prompts из настоящего лога и осмотреть. После установки сравнить исполняемый файл с проверенным артефактом, перезапустить установленную копию, проверить реальную карточку и Keep awake.

## Границы

Текущую установленную версию без обновлятора потребуется заменить один раз обычным способом. Публикация релиза, настройка секретов и замена установленного приложения — отдельные действия после проверки реализации. На этом этапе не добавляются каналы beta, собственный сервер обновлений или Apple notarization.

Основание: [интеграция и подписи Sparkle](https://sparkle-project.org/documentation/), [публикация обновлений](https://sparkle-project.org/documentation/publishing/).
